## Features

- Responsive dark-themed portfolio with a light/dark theme switcher.
- Three.js particle background, parallax layers, card tilt, and scroll reveal effects.
- Mobile navigation, scroll spy, and progress indicator.
- Knowledge and interest tabs, plus the interactive skill manager.
- Photo upload, printable resume modal, and validated demo contact form.

The contact form currently validates input but does not deliver messages. Email and social profile actions remain placeholders until real details are supplied.

## Run Locally

Open `index.html` in a browser, or start a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project Files

- `index.html` — portfolio content, metadata, and resume modal
- `style.css` — responsive visual design and theme styles
- `script.js` — animation and interaction logic
- `assets/images/profile-placeholder.svg` — generic temporary profile image
- `assets/images/favicon.svg` — AS monogram favicon
